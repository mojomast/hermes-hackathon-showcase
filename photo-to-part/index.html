A General notes

photo-to-part is one skill, photo-to-part:photo-to-printable-part, plus six tools. Hand it a photo, a few measurements, or a messy 3D scan, and it works toward a parametric part you can print or edit: templates first, then a local Python build behind an approval prompt, then validation and comparison renders held next to your photo.

On Hermes 0.23 or newer, an optional Part studio pane shows the stage, photo overlay, renders, history, scale and trust, approval, and output paths. The tools install without it.

  1. One skill (photo-to-part:photo-to-printable-part) and six tools
  2. Optional Part studio Desktop pane on Hermes 0.23+ showing stage, photo overlay, renders, history, scale/trust, approval, and output paths
  3. Templates including plate clip, spur gear, scroll, and strap hinge; builds are local Python with an approval prompt
  4. Validate watertight meshes and stated sizes; heal messy scans; render comparison views next to the photo
  5. User-stated millimetre values are not replaced by a photo measurement
  6. No credentials, no printer connection, no network from the tools; chat photos still go to your model provider

C Details: use cases

  1. D

    Detail D. Ask for a replacement part from a photo and a few measurements, then print a validated STL

  2. E

    Detail E. Make a fit-test print of a plate clip (the checked-in sample is 51 × 72.6 × 6 mm in examples/plate-clip)

  3. F

    Detail F. Turn a messy 3D scan into a healed solid with photo_part_heal, then validate and render views

  4. G

    Detail G. Generate a spur gear from stated module, tooth count, and bore, after the template path has been tried

  5. H

    Detail H. Model a strap hinge (one or two scrolls on a straight strap) and compare the photo overlay in the Part studio pane

  6. I

    Detail I. Hold rendered front/iso/side/top views next to the original photograph to check the fit before you print

L Assembly instructions

Install the plugin/ subdirectory so evals/ and tests/ are not copied into Hermes:

hermes plugins install mojomast/hermes-photo-to-part/plugin --ref d924991f56ad4cf7b94e33f2ac5dcb6cf24fac5f
hermes plugins enable photo-to-part

Until catalog acceptance the README also shows --no-enable first so you can read the code. After catalog acceptance the reviewed install is hermes plugins install photo-to-part. Load the skill with skill_view("photo-to-part:photo-to-printable-part"). Enabling the plugin installs its Python packages from PyPI after Hermes dependency consent. A STEP solid needs CadQuery or build123d in the project environment (optional, can take several minutes). A root install without /plugin is refused.

README documents unittest discover -s tests and hermes plugins validate / doctor --ci, but does not publish a test count.
