TEMPLEOS for Hermes

A local TempleOS-family guest in QEMU. The Hermes agent and you share one live screen.

In memory of Terry A. Davis (1969–2018), author of TempleOS. TempleOS is public domain. This plugin is an unofficial Hermes integration.

What it is[X]

The plugin runs a local TempleOS-family guest in a child QEMU, with networking always off (-nic none). The Hermes agent and you share one live screen in a Hermes Desktop pane. The agent reads the screen as text or as a 640×480 PNG, types and clicks, injects HolyC, and moves files over a framed COM1 protocol. You can take the keyboard at any time and hand it back.

QEMU and the ISOs are not bundled. Doctor fetches the official pinned ISO and verifies its SHA-256. The default guest is Temple of Hermes v0.1.2, a public-domain TinkerOS fork with an 18-entry home launcher, HBBS/1 boards over a COM2 serial modem, and a COM1 agent handshake.

Features[X]

  • Four tools: templeos_vm, templeos_screen, templeos_input, templeos_files
  • Default guest is Temple of Hermes 0.1.2; optional TinkerOS 5.20-rc10, stock TempleOS 5.03, or ZealOS
  • Shared live screen in a Hermes Desktop pane; take control / hand back
  • Networking is always off (-nic none); QEMU and ISOs are not bundled; ISOs are fetched from official pinned URLs and SHA-256 verified
  • HD Terry companion in the pane (original fan tribute, 2017 cap look); Hide Terry / Quotes controls
  • Optional HBBS/1 chat bridge is off by default; destination is the allow-list name bbs

Pane modes

Watch
You see the VM; only the agent injects input.
Shared (default)
Both can type. Your key/click pauses the agent ~2 s.
Take control
Agent tools return agent_paused until Hand back.

Use cases[X]

  1. Boot Temple of Hermes 0.1.2 and share the live guest screen with Hermes in the Desktop pane
  2. Let the agent type HolyC or shell commands while you watch, or take control and hand the keyboard back
  3. Switch guest OS from the pane's Guest OS picker (Temple of Hermes, TinkerOS, TempleOS 5.03, ZealOS) and reboot into it
  4. Read the screen as text or as a PNG (look defaults to 640×480) and push or pull files over the framed COM1 protocol
  5. Open the 18-entry home launcher in Temple of Hermes — click an icon or press its shortcut, then return to the launcher when the app exits
  6. Use HBBS/1 boards inside the guest over the COM2 serial modem, with no NIC on the VM

Install.HC[X]

Requires qemu-system-x86_64 and qemu-img on PATH (for example sudo apt install qemu-system-x86 qemu-utils).

hermes plugins install mojomast/hermes-templeos --ref c61d00eb4d36c5e3c7cd57a2985985aed8db42f0 --enable
hermes plugins doctor templeos

No ISO is bundled. Doctor fetches the official Temple of Hermes 0.1.2 ISO from its GitHub release and verifies SHA-256. Primary host is Linux x86_64; Apple Silicon and Windows are untested. Terry is an original fan tribute with no official TempleOS affiliation.
