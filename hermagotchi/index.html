So what is it?

Hermagotchi gives Hermes a native pane with Habitat, Battle, Shop, Leaderboard and Social tabs, plus a lobby rail. You raise a pet, battle other pets async, earn Bits, unlock cosmetics up to mythic tier, and talk trash in the lobby.

By default it's an offline practice sim: in memory, no network, and it resets when Hermes restarts. Online play is opt-in, and pairing a device stays a human action in the pane.

The agent drives eight hermagotchi_* tools. It can never buy items, and agent chat and autonomy stay off until you switch them on.

What's in the box

  • Exactly 8 composable hermagotchi_* tools and a native pane (Habitat, Battle, Shop, Leaderboard, Social, plus a lobby rail)

  • Offline practice simulation by default (in-memory, no network, resets on Hermes restart)

  • Optional hosted or self-hosted game API once network_enabled is turned on; pairing stays a human pane action

  • Care meters, Bits wallet, cosmetics up to mythic tier, deterministic async battles, seasonal leaderboard

  • Social layer: lobby, DMs, challenges, taunts — agent chat and autonomy are off until you opt in

  • The agent can never buy items; pet care/adopt are not gated by the autonomy setting

Care instructions

hermes plugins install mojomast/hermagotchi --ref 0ed7793fbf238e32fb86506ad2b587ae4eb90963
# or, once listed: hermes plugins install hermagotchi
hermes plugins enable hermagotchi

Network, autonomy, and agent chat stay off until you opt in via plugin settings or the documented environment variables. Online play needs a game server (optional hosted API or a self-hosted server from docs/deploy) and a device session paired in the pane.
