section "Why poptart"

Strudel is a fantastic way to make music in code. poptart turns it into a workspace: tracks that persist, revisions that guard against overwrites, sections you can switch between, and a clean agent API.

Your Hermes agent can draft a beat, add a break or change the tempo. You stay in control, because nothing plays until you press Play.

section "Main"

  1. + Live-coding Strudel/JS editor with tempo, Play/apply, Stop, and Mute
  2. + Scheduler-synced mini-notation highlights in the Hermes accent
  3. + Invalid edits keep the last good pattern playing and show the error separately
  4. + Persistent track library with revisions, snapshots, and named sections
  5. + One composable tool, poptart_studio, plus an opt-in Desktop/Webapp pane
  6. + Local-first: loopback-only Node sidecar, private per-install token, no hosted AI service

tool poptart_studio({ op, input })

One tool, eleven ops, a 127-token schema. There is deliberately no delete, shell, remote-playback or audio-export op, and agent edits never auto-play.

opinputwhat it does
list{}List tracks
get{trackId}Read one track (code, tempo, sections, revision)
create{title, code, tempo, sections}New track. Tempo 20–400
update{trackId, expectedRevision, changes}Change title, code, tempo or sections
update_section{trackId, expectedRevision, sectionId, section}Edit one section
sections{trackId}List a track's sections
snapshot{trackId, expectedRevision}Save a snapshot of the current revision
snapshots{trackId}List snapshots
restore{trackId, snapshotId, expectedRevision}Restore a snapshot
analyze{trackId}Static counts (no audio analysis)
export{trackId}Export the code (never audio)

library things to make

  • track 01

    Ask Hermes to draft a beat, add a break, or change the tempo through poptart_studio, then apply it yourself

  • track 03

    Keep several tracks with snapshots and switch named sections such as Intro, Main, or Break

  • track 04

    Watch tokens light up as they play, then edit without killing the groove if the new code is invalid

The installable plugin is the self-contained integration/hermes directory, not the repo root. Catalog installs need Node 22+, not npm or a local build.

hermes plugins install mojomast/poptart --ref 42356ddb9eff2eea2419bbd223ee159f353e4632

# hermes plugins install hermes-strudel-studio --enable
