The survey

Eye Of Hermes puts a live 3D globe in a Hermes Desktop or Webapp pane, and hands the agent the controls. The plugin (id godseye) drives a running God's Eye View checkout. Hermes can fly the camera, drop pins, draw routes and areas, query public data feeds, and leave watches running while you keep talking.

HUD summaries are written with the Hermes model through ctx.llm. Overlays live in a sidebar and export as eoh.overlays.v1. Some things are refused outright: person search, face recognition, and tracking an individual.

Legend

  • Live 3D globe pane in Hermes Desktop or the Webapp that Hermes can fly, pin, and watch

  • 11 composable godseye_* tools covering view, query, layers, feeds, annotate, nav, track, scene, watch, capture, and admin

  • Public data: aircraft, ships, satellites, earthquakes, fires, weather, infrastructure, and public SDR receivers

  • HUD summaries generated with the Hermes model (ctx.llm)

  • Overlays sidebar for pins, routes, trails, lines, areas, watches, and scenes, with eoh.overlays.v1 import/export

  • Director scenes, pin clips (YouTube or X URLs), imagery compare, measure, and fire_check

  • Person search, face recognition, and tracking an individual are refused

Waypoints · what to ask it for

  1. WP 01

    Ask Hermes to brief a city and fly the globe there — for example brief-and-show Tokyo or San Diego from chat

  2. WP 02

    Compare before-and-after imagery on the pane, including fire_check (FIRMS plus clearest recent image, then imagery before/after)

  3. WP 03

    Measure distances or areas on the globe and keep the result on the pane

  4. WP 04

    Leave an area watch running for quakes, fires, or public aircraft/ships, with alerts quoted as third-party text

  5. WP 05

    List nearest public SDR receivers (godseye_query op=sdr_receivers) and inspect the public SDR / waterfall layer in Europe or Berlin

  6. WP 06

    Build a Director scene of pins and routes, or open a pin drawer with an attached clip, from the Overlays sidebar

Field instructions

hermes plugins install mojomast/EOH --ref 9d433e49645df8ee549b58467876eb1e5daa0f34
hermes plugins enable godseye

The plugin id is godseye. Once the catalog entry is merged you can also install by catalog name: hermes plugins install godseye.

Requires Node 24 or newer and a running God's Eye View checkout (mojomast/gods-eye-view main at or after b361a25 for the public SDR layer). Optional map credentials are declared in plugin.yaml and read through Hermes secrets. The one-click install link in the README is hermes://plugin/install?repo=mojomast/EOH.
